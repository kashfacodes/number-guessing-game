# Number Guessing Game 🎯

A beginner-friendly Python number guessing game where the player tries to guess a randomly generated number.

## Features

- 🎚️ Three difficulty levels
- 🎲 Randomly generated numbers
- 🔢 Limited number of attempts
- ⬆️ Too high / too low hints
- 🚫 Invalid input handling
- 🧮 Attempt counter
- 🔄 Play again option

## How to Play

1. Run `guessing_game.py`
2. Choose a difficulty level.
3. Enter your guesses.
4. The game tells you whether your guess is too high or too low.
5. Try to guess the number within the allowed attempts.
